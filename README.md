# Smedico App

Configuración inicial del workspace Angular 20 (standalone) basada en el plan de implementación por etapas.

## Requisitos previos
- Node.js 18 LTS o superior
- npm 9 o superior

## Instalación
```bash
npm install
```

## Desarrollo
```bash
npm start
```

## Construcción de producción
```bash
npm run build
```
